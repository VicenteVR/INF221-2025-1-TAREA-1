En esta tarea se implementaron y analizaron diversos algoritmos de ordenamiento y de multiplicación de matrices.

Se desarrollaron algoritmos como SelectionSort, MergeSort, QuickSort y std::sort para el ordenamiento de arreglos unidimensionales, y algoritmos de multiplicación de matrices como Naive y Strassen.

Se realizaron experimentos para medir el tiempo de ejecución y el consumo de memoria de cada algoritmo, utilizando conjuntos de datos de diferentes tamaños. Los resultados experimentales fueron graficados y analizados, observándose diferencias en el comportamiento de los algoritmos según el tamaño y tipo de entrada.
